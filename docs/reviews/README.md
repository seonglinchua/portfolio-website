# Review archive

This folder contains UX, visual, and accessibility review artifacts for the Nezha Systems website.

- `section-review.md` is the latest section-by-section assessment.
- `website-review.md` is the initial holistic assessment.
- `design-qa.md` records the earlier source-comparison status.
- `evidence/` contains screenshots supporting those findings.

Run `npm run audit:capture` or `npm run audit:sections` while the development server is available at port 4173 to create a fresh capture set under `evidence/current/`.
